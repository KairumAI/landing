D-005

Para una agencia argentina que vende autos de distintas marcas, ¿cuándo conviene un banco, una financiera o un intermediario de crédito?

Corte 9 sep 2026 · Agente Codex con búsqueda web

Respuesta completa

Texto original del agente, conservado sin cambios. Las fuentes listadas son las que enlazó esta respuesta; no implican una auditoría de sus afirmaciones.

Para una agencia argentina multimarca, suele convenir un esquema mixto: - **Banco:** cuando el cliente tiene buen perfil crediticio y busca el menor costo total. Es útil para préstamos prendarios, montos altos y plazos más largos. Permite comparar tasas y condiciones mediante el régimen de transparencia del BCRA. [BCRA: productos financieros](https://www.bcra.gob.ar/regimen-de-transparencia/) - **Financiera:** cuando importan más la rapidez, la aprobación en el punto de venta y la flexibilidad para perfiles que el banco rechaza. Puede ofrecer campañas, scoring propio o financiación para determinados modelos. La contrapartida habitual es un costo financiero potencialmente mayor. “Financiera” puede significar una compañía financiera regulada o una empresa no financiera que presta: conviene verificar exactamente quién otorga el crédito. - **Intermediario de crédito:** cuando la agencia quiere ofrecer muchas alternativas sin prestar con fondos propios ni asumir directamente el riesgo de incobrabilidad. Es especialmente atractivo para una operación multimarca: el intermediario puede comparar varias entidades, centralizar documentación y cobrar una comisión por originación. Debe quedar claro quién es el acreedor, quién fija la tasa y quién responde por el contrato. **Regla práctica:** banco para clientes “prime” y precio; financiera para conversión, velocidad y mayor flexibilidad; intermediario para variedad, escala y menor riesgo patrimonial de la agencia. **Puntos regulatorios confirmados:** si la agencia otorga crédito habitualmente con fondos propios, puede encuadrar como proveedor no financiero de crédito y tener obligaciones de registro, información y reporte al BCRA. La inscripción no habilita por sí sola a captar depósitos ni a realizar intermediación financiera. [BCRA: proveedores no financieros](https://www.bcra.gob.ar/proveedores-no-financieros/) [BCRA: normas aplicables](https://web2.bcra.gob.ar/Pdfs/Texord/t-apnf.pdf) Además, en créditos para consumo deben informarse claramente precio de contado, monto financiado, tasa efectiva anual, CFT, cuotas, seguros y gastos; si el crédito de un tercero no se obtiene, la operación queda condicionada y no debería generar costo para el consumidor. [Ley 24.240, artículo 36](https://www.argentina.gob.ar/normativa/nacional/ley-24240-638/actualizacion) No se puede confirmar una opción universalmente más barata o rentable: depende de tasas vigentes, comisiones, aprobación, mora, mix de clientes y acuerdos comerciales.
