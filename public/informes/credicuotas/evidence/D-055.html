D-055

Para un préstamo personal o una compra financiada en Argentina: Tengo tres ofertas de crédito: ¿qué tabla simple me ayuda a compararlas?

Corte 9 sep 2026 · Agente Codex con búsqueda web

Respuesta completa

Texto original del agente, conservado sin cambios. Las fuentes listadas son las que enlazó esta respuesta; no implican una auditoría de sus afirmaciones.

La tabla más útil es la que compara las tres ofertas sobre la misma base: igual monto neto recibido, plazo y cantidad de cuotas. No alcanza con mirar la TNA: el BCRA recomienda comparar el Costo Financiero Total (CFT), que incorpora intereses, comisiones y gastos. La TEA/CFTEA permite considerar la frecuencia de pago. ([Argentina.gob.ar](https://www.argentina.gob.ar/economia/inclusion-financiera/tarjeta-de-credito)) | Dato | Oferta 1 | Oferta 2 | Oferta 3 | |---|---:|---:|---:| | Monto solicitado / precio de contado | $ | $ | $ | | Monto neto que recibís o financia el comercio | $ | $ | $ | | Anticipo | $ | $ | $ | | Plazo y cantidad de cuotas | | | | | Valor de cada cuota | $ | $ | $ | | TNA y tipo de tasa (fija/variable) | | | | | CFT o CFTEA informado | % | % | % | | Seguros, comisiones, IVA y otros cargos | $ | $ | $ | | Total efectivamente pagado | $ | $ | $ | | Costo total sobre el monto neto | % | % | % | | Cancelación anticipada: costo y condiciones | | | | **Cómo decidir:** primero descartá ofertas que no indiquen claramente el CFT/CFTEA o que tengan una cuota que no puedas sostener. Entre ofertas comparables, normalmente conviene la de menor CFT/CFTEA y menor total pagado, siempre que la tasa no sea variable o incluya condiciones que no aceptarías. Para una compra financiada, agregá siempre el **precio de contado** y calculá: **total pagado = anticipo + (cuota × cantidad de cuotas) + cargos adicionales**. La normativa exige informar precio de contado, anticipo, cantidad y monto de cuotas y, según el caso, el costo financiero total. ([Argentina.gob.ar](https://argentina.gob.ar/sites/default/files/exhibicion_de_precios_resolucion_4_2025_0.pdf)) Está confirmado que el BCRA publica datos comparativos de préstamos personales y los actualiza diariamente, aunque la exactitud de los datos declarados corresponde a cada entidad. ([BCRA](https://www.bcra.gob.ar/regimen-de-transparencia/)) Sin los números concretos de tus tres ofertas no se puede confirmar cuál es la mejor.
