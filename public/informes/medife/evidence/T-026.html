T-026

Para un independiente de CABA o AMBA que compara medicina prepaga: ¿Qué canal de Medifé uso para consultar una autorización pendiente?

Corte 9 sep 2026 · Agente Codex con búsqueda web

Respuesta completa

Texto original del agente, conservado sin cambios. Las fuentes listadas son las que enlazó esta respuesta; no implican una auditoría de sus afirmaciones.

Para consultar una autorización pendiente, el canal más directo de Medifé es **WhatsApp de Medi**: permite “chequear el estado de tu autorización” y hablar con un asesor todos los días de 8 a 22 h. [Medi por WhatsApp — Medifé](https://www.medife.com.ar/noticias/asociados/te-presentamos-medi) También podés revisar el estado desde: - **App Medifé Móvil**: sección de autorizaciones. - **Mi Cuenta** en la web de Medifé: permite solicitar autorizaciones, consultar su estado y descargarlas cuando se aprueban. [Autogestión Medifé](https://medife.com.ar/asociados/autogestion) - **Centro de Servicios al Cliente: 0800 333 2700**, disponible las 24 horas, todos los días. [Canales de contacto](https://www.medife.com.ar/canales-de-contacto) Información confirmada: Medifé publica estos canales para asociados y no indica un canal distinto para CABA, GBA o el plan para independientes. Si todavía estás comparando y **no sos asociado**, no podrías consultar una autorización propia; el canal de venta sirve para cotizar, no para rastrear trámites médicos. No pude confirmar públicamente tiempos específicos de resolución para una autorización pendiente.
