D-031

Para una empresa o comercio que necesita cobrar en Argentina: ¿qué redes y proveedores de cobranza puedo investigar para evaluar integración con sistemas de facturación? El caso es el de una empresa con software propio.

Nota de revisión KAIRUM

Cómo interpretar esta respuesta

Respuesta observada en esta muestra. Provincia NET/NET Pagos, Banco Provincia y Cuenta DNI cumplen roles diferentes. El estudio contempla la empresa que recauda y el comercio que busca ser punto de pago; sus requisitos y condiciones no se trasladan entre recorridos. Una oferta integrable o un portal autenticado no prueban públicamente sus endpoints, formato de conciliación, sandbox, SLA ni una implementación para cualquier cliente.

Para una empresa argentina con software propio, conviene investigar estas categorías: **Proveedores de pagos online y adquirencia** - **Mercado Pago**: ofrece Checkout API, SDKs, links de pago, QR, Point, suscripciones, reembolsos, contracargos y webhooks. Es una opción rápida para centralizar medios de pago. [Documentación de Mercado Pago Developers](https://www.mercadopago.com.ar/developers/es/docs/getting-started) - **Payway**: permite integración propia mediante API o SDK, además de plugins. Acepta tarjetas y medios como MODO, Cuenta DNI y Mercado Pago, según habilitación comercial. [Payway Ventas Online](https://www.payway.com.ar/vender-online) - **Fiserv**: publica APIs para pagos, consultas, anulaciones, reembolsos, links, tokenización y esquemas recurrentes. La disponibilidad concreta para Argentina y las condiciones de acceso deben validarse con Fiserv. [API de Fiserv](https://docs.apis-fiserv.com/latam/docs/introduction-1) - **Getnet**: ofrece API Checkout, links de pago, suscripciones e integración para sitios y aplicaciones propias. [Cobros online de Getnet Argentina](https://www.getnet.net/ar/nuestras-soluciones/cobros-online) - **Naranja X**: informa integración API para e-commerce, QR interoperable, links, cobros presenciales y débito automático. La documentación técnica pública y el alcance para software propio requieren confirmación comercial. [Naranja X Comercios](https://www.naranjax.com/comercios) - **MODO**: en ventas online utiliza Payway como procesador; requiere cuentas, API keys y credenciales de MODO. No debería evaluarse como una pasarela completamente independiente sin revisar ese esquema. [Integración de MODO](https://www.modo.com.ar/comercios/tiendas-online/boton-de-pago) **Redes de cobranza y pagos de facturas** - **PagoMisCuentas/Banelco**: permite cobrar online, desde apps bancarias, billeteras, puntos de pago y cajeros; ofrece consulta de deuda, alta de factura y avisos de pago vía API/webservice. [PagoMisCuentas Empresas](https://pagomiscuentas.com.ar/empresas) - **Red Link/Link Pagos**: dispone de APIs para consulta de deudas y pagos de entes. [API Pagos de Red Link](https://portal.api.redlink.com.ar/redlink/produccion/taxonomy/term/718) - **Pago Fácil** y **Rapipago**: sirven para cobranza extrabancaria, especialmente efectivo. Ambos indican adhesión empresarial y mecanismos de integración, pero el alta, formato de archivos/API y liquidación deben confirmarse. [API de Pago Fácil](https://www.pagofacil.net/api), [Rapipago para empresas](https://rapipago.com.ar/rapipagoWeb/agentes) **Importante:** cobrar y facturar son integraciones distintas. El software puede conectarse a ARCA mediante WSFE/WSMTXCA, o usar un facturador intermediario. [Webservices de factura electrónica de ARCA](https://arca.gob.ar/ws/documentacion/ws-factura-electronica.asp) No se puede confirmar públicamente, sin cotización y onboarding, disponibilidad de sandbox, comisiones, plazos de acreditación, límites, split de pagos, débito automático, homologación, soporte ni condiciones PCI. También conviene verificar cada proveedor en los registros del BCRA. [Registro de proveedores de servicios de pago del BCRA](https://www.bcra.gob.ar/registro-de-proveedores-de-servicios-de-pago/)
