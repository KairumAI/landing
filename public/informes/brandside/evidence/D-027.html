D-027

¿Qué agencias de branding argentinas publican información suficiente sobre proceso y entregables para pedir una propuesta de una app nueva?

Corte 2026-09-17 · codex-agent-web

Respuesta completa

Sí. Según la información pública disponible, estas son las opciones más adecuadas para pedir una propuesta: - **COCO (CABA)**: la mejor coincidencia para una app nueva que necesite marca y producto digital. Publica investigación, estrategia, arquitectura de información, user flows, wireframes, UI, prototipado y validación. Entrega prototipos interactivos, archivos de diseño, librería Figma, guías de interacción y documentación para desarrollo. [Brochure de COCO](https://cancilleria.gob.ar/userfiles/ut/coco-branding_-ux-ui-2025-esp.pdf) - **Uxion Agency**: especialmente clara para diseño UX/UI de apps móviles iOS y Android. Detalla investigación, user flows, wireframes, prototipos, testing, sistema visual y colaboración con desarrollo. Declara como entregables research, diseño en Figma, prototipos navegables, Design System y assets listos para desarrollo. [Proceso y entregables UX/UI](https://www.uxionagency.com/servicios/agencia-diseno-ux-ui) [Diseño UI](https://www.uxionagency.com/servicios/agencia-diseno-ux-ui/ui) - **AgenciaMH (Buenos Aires)**: buena candidata si el proyecto comienza por branding y continúa con UX/UI. Publica estrategia, identidad visual, naming, diseño web y UX/UI; además muestra casos específicos de apps, como MIA y CAPO Viagens. [Portfolio y servicios](https://agenciamh.com/es/trabajo) - **Upa Estudio (Buenos Aires)**: recomendable para construir la marca y su aplicación digital. Explicita estrategia, identidad, naming, manuales, templates, bibliotecas de assets y dirección de UI; también exhibe un caso de app móvil y UI web. [Proceso, modalidades y entregables](https://upaestudio.com.ar/) - **prieto (Córdoba)**: opción más orientada a diseño y desarrollo web, con UX/UI, branding, aplicación web, estrategia UX, prototipado en Figma, desarrollo y soporte. Conviene confirmar si toman apps móviles nativas. [Proceso y planes](https://prietoagency.com.ar/) La información pública alcanza para solicitar propuestas comparables, pero habría que pedir confirmación sobre desarrollo móvil, backend, publicación en stores, testing con usuarios, mantenimiento y presupuesto.
