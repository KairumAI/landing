Nota de revisión KAIRUM

Cómo interpretar esta respuesta

Respuesta observada sobre colchones y descanso. Los atributos y condiciones se atribuyen a sus fuentes; no se probaron productos ni se realizó una compra. La cobertura evalúa información para la pregunta, no veracidad, calidad, confort o resultado comercial. El envío publicado excluye Tierra del Fuego y una sola almohada tiene cargo. Plazo y disponibilidad dependen del producto, código postal y pedido. La entrega estándar es en planta baja; Entrega de Ensueño es un servicio adicional con sus propias condiciones. No se ingresaron datos personales, pedidos, medios de pago ni formularios de soporte. Se revisó sólo información pública; un canal o formulario no acredita una solicitud efectuada.

Alcance: revisé las páginas públicas de Calm sin completar formularios ni avanzar con datos personales. La lista exacta de campos del checkout no pudo confirmarse desde la vista pública. **Pasos que sí se observan:** 1. Elegir el producto y, cuando corresponde, tamaño, color o variante. 2. Consultar la entrega ingresando únicamente el código postal; el sitio lo muestra en las fichas de producto para calcular disponibilidad, costo o plazo ([ejemplo: Colchón Calm](https://calmessimple.com.ar/producto/colchon-calm)). 3. Agregar el producto al carrito. 4. En el pedido, elegir envío a domicilio o retiro. Calm explica que el retiro se selecciona como método de envío durante la compra ([Pick Up](https://calmessimple.com.ar/pick-up)). 5. Seleccionar el medio de pago y confirmar. La empresa publica tarjetas Visa, Mastercard, American Express, Naranja, MODO y transferencia bancaria, con financiación variable según producto ([Métodos de pago](https://calmessimple.com.ar/metodos-de-pago); [Preguntas frecuentes](https://calmessimple.com.ar/preguntas-frecuentes)). **Datos que el proceso contempla:** - Código postal, para evaluar entrega. - Una dirección de correo electrónico: Calm indica que envía por mail la factura y las actualizaciones del pedido; también menciona seguimiento mediante correo electrónico y número de pedido. - Para envío a domicilio, presumiblemente datos de entrega —por ejemplo, destinatario y domicilio—. - Datos de facturación. Para solicitar Factura A, la empresa indica que se requiere CUIT y razón social; para consumidor final, Factura B ([Preguntas frecuentes](https://calmessimple.com.ar/preguntas-frecuentes)). **No confirmado sin ingresar datos:** los nombres exactos de todos los campos obligatorios, si exige DNI, teléfono, domicilio completo desglosado, creación de cuenta, aceptación de términos o qué datos solicita directamente la pasarela de pago. Por lo tanto, no sería correcto afirmar que cada uno de esos datos sea obligatorio en todos los casos.
